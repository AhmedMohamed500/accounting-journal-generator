# FINORA Service Point — Zero-Cost Demo Edition

## الغرض

نسخة عرض تجارية تعمل بالكامل داخل المتصفح من دون Backend أو قاعدة بيانات أو خدمة مدفوعة. هدفها أن يجرب العميل دورة تشغيل مقنعة قبل تفعيل النسخة السحابية.

## بدء التجربة

افتح `/ar/service-point` أو `/en/service-point` واختر أحد المسارين:

- **جرّب بنموذج جاهز:** ينشئ محل Demo مع وردية وكاشير وأرصدة فوري والمحافظ وعمليات وربح وعملية معلقة.
- **ابدأ نشاطك من الصفر:** Wizard من 7 خطوات ينشئ النشاط والمحل والخدمات والأرصدة والكاشير والباقة وأول وردية.

بيانات الدخول الجاهزة للعرض:

- Owner PIN: `5678`
- Cashier PIN: `1234`

هذه PIN محلية للتجربة فقط، ومحفوظة كـSHA-256 مع Salt وليست Authentication إنتاجية.

## سيناريو عرض مقترح للعميل

1. ابدأ بالنموذج الجاهز.
2. اعرض الخزنة وأرصدة فوري والمحافظ في مركز القيادة.
3. سجل عملية جديدة وشاهد المعاينة قبل الترحيل.
4. افتح لوحة المالك من الهاتف أو وضع Responsive وأخفِ القيم المالية.
5. اعرض تقرير اليوم وربح كل خدمة وأداء الكاشير وفروق الإقفال.
6. افتح سجل النشاط ثم نزّل Backup.
7. افتح `/ar/service-point/plans` وبدّل بين الشهري والسنوي.
8. اختر Pro واعرض كود طلب التفعيل اليدوي.

## Sales Demo Mode وReset

من إعدادات Service Point يمكن إنشاء **Sales Demo Mode**. ينشئ النظام محلًا تجريبيًا مستقلًا ويسجل معرّفه في إعدادات التجربة. أمر **Reset Sales Demo** يحذف بيانات ذلك المحل التجريبي فقط ولا يمس المحلات التي أنشأها العميل في Empty Mode.

## Backup

زر Backup ينزل ملف JSON يشمل:

- إعدادات النشاط والخدمات.
- المحلات والورديات والعمليات والقيود.
- المستخدمين المحليين وPIN hashes.
- سجل النشاط المحلي.
- حالة التجربة والباقة ودورة الفوترة.

يظهر تذكير داخل النظام إذا لم تُنشأ نسخة خلال 7 أيام. لا تستخدم النسخة Push Notifications أو تخزينًا سحابيًا.

## Restore

اختر ملف JSON صادرًا من FINORA. تظهر معاينة باسم النشاط وعدد المحلات والعمليات وتاريخ النسخة. بعد التأكيد تُستبدل بيانات Service Point المحلية الحالية بالنسخة. يفضل تنزيل Backup جديد قبل الاستعادة.

## Trial والباقات

- مدة التجربة الافتراضية: 14 يومًا.
- الحالات: `trial` و`active-demo` و`expired-demo` و`cancelled-demo`.
- انتهاء التجربة لا يحذف البيانات ولا يمنع العرض أو الطباعة أو Backup.
- التفعيل يدوي للعرض، ولا توجد Payment Gateway أو Checkout وهمية.

الإعداد المركزي موجود في `data/service-point-plans.ts`:

- `trialDays`: مدة التجربة.
- `annualFreeMonths`: عدد الأشهر المجانية سنويًا.
- `backupReminderDays`: مدة تذكير Backup.
- `plans`: الأسعار والحدود والمزايا العربية والإنجليزية.

تعديل السعر يحتاج تغيير `monthlyPrice` في هذا الملف فقط؛ تحسب الواجهة السعر السنوي تلقائيًا.

## المستخدمون والصلاحيات

الأدوار المحلية:

- Owner: كل الوظائف.
- Manager: الورديات والعمليات والاسترداد والتقارير والنسخ الاحتياطي.
- Cashier: الوردية الحالية والعمليات والإيصالات.
- Accountant: التقارير والقيود والنسخ الاحتياطي.
- Viewer: قراءة التقارير فقط.

القيود مطبقة في الواجهة ومحرك أفعال Service Point، لكنها قابلة للتجاوز عبر أدوات المتصفح لعدم وجود خادم.

## سجل النشاط

يسجل محليًا تسجيل الدخول، فتح وإقفال الوردية، إنشاء العملية، اعتماد المعلقة، الاسترداد، إنشاء المستخدم، اختيار الباقة، النسخ والاستعادة، وإنشاء أو مسح Demo. السجل قابل للتعديل من المتصفح وليس Immutable security log.

## تجربة الأجهزة

الصفحات مصممة للعرض من 320px حتى Desktop، مع Bottom Navigation على الهاتف، بطاقات مرنة، وجداول ذات تمرير داخلي. لوحة المالك توجد على `/ar/service-point/owner-dashboard` ونسختها الإنجليزية.

كل Browser يحتفظ ببياناته الخاصة. عند فتح الرابط على هاتف جديد يمكن بدء Demo موبايل مستقلة. لا توجد مزامنة بين الهاتف والكمبيوتر في Demo Edition.

## Cloud Edition Preview

المزايا التالية معروضة للبيع لكنها غير منفذة محليًا:

- Multi-device sync.
- Secure authentication.
- Automatic cloud backup.
- Central immutable audit trail.
- Remote Owner Dashboard.
- تكامل رسمي مع Fawry APIs ومقدمي الخدمات.

## القيود الحالية

- لا Backend أو Database أو API خارجية.
- لا اتصال فعلي بفوري أو المحافظ.
- لا تنفيذ تحويلات تلقائي.
- لا Payment Gateway أو SMS أو WhatsApp API.
- لا مزامنة أو نسخ احتياطي تلقائي بين الأجهزة.
- `localStorage` قابل للمسح والتعديل من المستخدم.
- Offline behavior يعتمد على ما خزنه المتصفح بعد تحميل الموقع، ولا توجد مطالبة بأن النظام PWA كامل.
