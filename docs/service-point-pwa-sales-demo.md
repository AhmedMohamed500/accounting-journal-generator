# FINORA Installable PWA + 5-Minute Interactive Sales Demo

آخر تحديث: 4 سبتمبر 2026

## النتيجة

أصبح FINORA Service Point تطبيق ويب قابلًا للتثبيت، مع تجربة مبيعات تفاعلية مستقلة مدتها نحو خمس دقائق. رابط التجربة المباشر:

- العربية: `https://accounting-journal-generator.vercel.app/ar/service-point/demo`
- English: `https://accounting-journal-generator.vercel.app/en/service-point/demo`

التطبيق Local-first: بيانات الجهاز تبقى في `localStorage`، والعمل دون اتصال لا يعني وجود مزامنة سحابية. Cloud Edition معروضة كتطوير مستقبلي وغير مفعلة في هذه النسخة.

## مكونات الـPWA

- Manifest باسم FINORA، وضع `standalone`، ألوان العلامة، اختصارات Service Point ولوحة المالك والديمو.
- أيقونات 192 و512 بكسل وأيقونة maskable.
- Service Worker آمن يخزن App Shell والملفات الثابتة، ويستخدم Network-first للصفحات مع صفحة `/offline` عند تعذر الشبكة.
- حذف الكاشات القديمة عند التفعيل وتحديث صريح عبر زر، من دون حذف بيانات النشاط أو بيانات `localStorage`.
- التقاط `beforeinstallprompt` في Chromium، وإرشاد iOS عبر Share ثم Add to Home Screen، واكتشاف وضع التطبيق المثبت.
- حالة اتصال واضحة، إصدار `2026.09.04`، تقدير مساحة البيانات المحلية، وتوضيح أن Cloud Sync غير مفعلة.
- دعم safe areas وBottom Navigation على الشاشات الصغيرة وفي وضع standalone.

## مسار تجربة الخمس دقائق

تبدأ الشاشة بثلاثة اختيارات: تجربة تفاعلية، بيانات عرض كاملة، أو بدء نشاط حقيقي. الجولة التفاعلية تستخدم Dataset مستقلة وحتمية:

1. فتح وردية بخزنة 20,000 ج.م وأرصدة خدمات مستقلة.
2. عملية فوري بقيمة 1,000 ج.م، عمولة عميل 10 ج.م، تكلفة مقدم خدمة 2 ج.م، وصافي ربح 8 ج.م.
3. عملية Vodafone Cash سريعة توضح استقلال رصيد كل مقدم خدمة.
4. عملية 500 ج.م معلقة لا تحرك الخزنة أو رصيد الخدمة.
5. تنبيه انخفاض رصيد فوري صادر من قواعد التوصية المحلية الفعلية.
6. لحظة لوحة المالك: الربح والخزنة والأرصدة والعمليات والكاشير.
7. إقفال الوردية بخزنة فعلية تقل 100 ج.م عن المتوقع، ثم عرض الملخص اليومي والإجراء المقترح.

كل عملية ناجحة تمر بمحرك Service Point وقيوده المحاسبية الموجودة. العملية المعلقة لا تنشئ حركة مالية. الجولة تحفظ التقدم، تعرض الاستكمال بعد إعادة التحميل، وتسمح بالتخطي أو إعادة البدء. Reset يحذف Store التجربة فقط ولا يمس بيانات النشاط الحقيقي.

## تغيير بيانات العرض

القيم المركزية موجودة في `data/service-point-sales-demo.ts`. يمكن تعديل اسم النشاط والكاشير والخزنة الافتتاحية وأرصدة الخدمات والعمليات التجريبية وفرق الإقفال من هذا الملف. لا تضع KPI نهائيًا يدويًا في الواجهة؛ اترك المحركات تحسب الخزنة والربح والتكلفة والفروق.

لإضافة خطوة جديدة:

1. أضف رقم الخطوة ونصوصها إلى `components/pos/service-point-sales-demo.tsx`.
2. نفّذ Action معزولًا في `lib/storage/service-point-sales-demo.ts` باستخدام محركات `lib/pos` الحالية.
3. حدّث حد الخطوات في `lib/pos/sales-demo.ts` واختبارات `tests/service-point-pwa-sales-demo.test.ts`.
4. اختبر الاستكمال وإعادة الضبط والعربية والإنجليزية وأصغر عرض 320px.

## التحويل إلى الباقات

نهاية الجولة تقترح باقة وفق قواعد المزايا التي ظهرت، وليست توصية ذكاء اصطناعي. صفحة الباقات تنشئ ملخص طلب اشتراك قابلًا للنسخ يحتوي النشاط والباقة ودورة الفوترة وكود الطلب. لا يوجد Checkout أو دفع أو تفعيل سحابي وهمي.

## التشغيل والتحقق

```bash
node node_modules/typescript/bin/tsc --noEmit
node node_modules/eslint/bin/eslint.js . --max-warnings=0
node node_modules/vitest/vitest.mjs run
node node_modules/next/dist/bin/next build
```

يجب التحقق كذلك من manifest والأيقونات وتسجيل Service Worker، ثم تجربة الجولة في العربية والإنجليزية، وإعادة التحميل أثناء الجولة، ووضع offline، والمقاسات 320 و360 و390 و430 و768 و820 و1024 و1440 بكسل.

## حدود النسخة الحالية

- لا يوجد Backend أو حسابات مستخدمين أو مزامنة أجهزة.
- أول تحميل على جهاز جديد يحتاج اتصالًا؛ المتاح offline بعد ذلك يعتمد على الملفات التي خزنها المتصفح.
- تثبيت iOS يتم يدويًا من قائمة Share، ولا يدعم حدث التثبيت نفسه الموجود في Chromium.
- تكامل فوري والمحافظ الحقيقي يحتاج اتفاقيات وواجهات Backend واعتمادات أمنية خارج نطاق الديمو.
